# Telegram-бот на бесплатных моделях OpenRouter

Простой Telegram-бот на Node.js ([grammY](https://grammy.dev)), который отвечает через бесплатные модели [OpenRouter](https://openrouter.ai).

## Возможности

- Диалог с памятью: бот помнит последние 10 сообщений каждого чата.
- Понимает изображения: фото и картинки, отправленные как файл (подпись к фото используется как вопрос).
- Цепочка моделей: если одна модель перегружена (429/5xx), бот повторяет запрос и переходит к следующей.
- Команды: `/start` — приветствие, `/reset` — очистить историю диалога.
- Длинные ответы автоматически режутся под лимит Telegram (4096 символов).

## Требования

- Node.js 20.6 или новее
- Токен бота от [@BotFather](https://t.me/BotFather)
- Ключ [OpenRouter](https://openrouter.ai/keys)

## Установка и запуск

```bash
npm install
```

Создайте файл `.env` в корне проекта:

```env
API_KEY=ваш_ключ_openrouter
TELEGRAM_BOT_TOKEN=токен_от_BotFather
```

Запуск:

```bash
npm start
```

## Настройка

Необязательные переменные в `.env`:

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `MODELS` | Текстовые модели через запятую, по порядку приоритета | `nvidia/nemotron-3-ultra-550b-a55b:free`, `google/gemma-4-31b-it:free`, `openrouter/free` |
| `VISION_MODELS` | Модели для изображений | `nvidia/nemotron-3.5-super-vl:free`, `google/gemma-4-31b-it:free`, `openrouter/free` |
| `SYSTEM_PROMPT` | Системный промпт бота | см. `bot.js` |

Актуальный список бесплатных моделей: <https://openrouter.ai/models?q=free>.

## Лимиты бесплатного уровня

У моделей с суффиксом `:free` ограничено число запросов (примерно 20 в минуту и 50 в день; после разового пополнения баланса на $10 дневной лимит вырастает до 1000). Кроме того, провайдер может временно отвечать ошибкой 429 из-за общей нагрузки. Именно поэтому в боте есть повторы и запасные модели.

## Безопасность

Файл `.env` содержит секреты и не должен попадать в git — он уже добавлен в `.gitignore`.
